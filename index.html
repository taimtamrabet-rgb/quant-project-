Interview Cheat Sheet

Percent change
How much a price moved, as a fraction of the starting price, times 100.
Expected value
The average outcome you'd expect over many repeats of a bet, found by weighting each outcome by its probability.
Fermi estimate
A rough, order-of-magnitude answer built from reasonable assumptions — real interviews grade closeness, not exactness.
Function
A reusable block of code that takes inputs and returns an output.
Test case
A specific input paired with the output it should produce — used to check that code actually works.
Debugging
Finding and fixing the part of your code that's producing the wrong result.
